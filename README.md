# PlaylistMaker

## Описание проекта
PlaylistMaker — это мобильное приложение для поиска, прослушивания и управления музыкальными треками с использованием iTunes API. Приложение позволяет:
- Искать треки через iTunes API.
- Проигрывать найденные треки.
- Добавлять треки в "Избранное".
- Создавать собственные плейлисты и управлять ими.


### Используемый стек технологий
- **Архитектура**: MVVM
- **Библиотеки**:
  - Glide (загрузка изображений)
  - Retrofit (сетевые запросы)
  - Room (локальное хранилище)
  - Koin (Dependency Injection)
  - Coroutines (асинхронная работа)

## Инструкция по развёртыванию
### Системные требования
- Android Studio (актуальная версия)
- JDK 11+
- Подключённый интернет для работы с iTunes API

### Установка и запуск
1. **Клонируйте репозиторий:**
   ```sh
   git clone https://github.com/RURURuina/PlaylistMaker.git
   ```
2. **Откройте проект в Android Studio.**
3. **Установите зависимости** через Gradle.
4. **Настройте API-ключ iTunes (если требуется).**
5. **Запустите приложение на эмуляторе или реальном устройстве.**
